# Beta report templates (copy and paste)

For testers who use the in-app **Send feedback** box, which holds **1,000 characters**. The GitHub issue forms in `.github/ISSUE_TEMPLATE/` ask for the same things, with more room.

Never include a password, your email address, a verification or reset link, or a screenshot that shows them. Safety and security problems go to the private support address in `docs/SUPPORT_AND_REPORTING.md`, not here.

## Bug report (choose "A problem")

```
Game / screen:
What I did (steps):
1.
2.
3.
What I expected:
What happened instead:
Any message shown (copied exactly):
Device + browser:
Wi-Fi or mobile data, and country:
Time it happened (with time zone):
Table code (if at a table):
How bad: [can't play / broken, no workaround / annoying / small]
Unfair or lost result? [yes / no]
```

## Feedback (choose "An idea" or "Something else")

Give each line a score from 1 (poor) to 5 (great), or "n/a", and add a few words.

```
Game(s) played:
Device + browser:
Usability (easy to find and understand?): /5
Mobile (fits the screen, easy to tap?): /5
Fairness (dice, cards, turns, scores): /5
Speed: /5
Reliability (disconnects, crashes, lost games): /5
Best thing:
Most annoying thing:
One change I would make first:
```
