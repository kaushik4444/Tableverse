# Changelog

## Unreleased (on `development`, not yet on `main`)
- Sudoku solo rating: a solo game gives a rating per difficulty (solo-easy, solo-medium, solo-hard), separate from race play. It is an Elo-style rating against a fixed par rating: a solve within par is a win, a slower solve half, a game over a loss. Shown on the table beside the lives. Par times are placeholders to tune from real solve times.
- New game: Sudoku (1–8 players; solo is for Sudoku only). Everybody gets the same generated puzzle on their own 9×9 grid; the first grid completed with every number right wins. Each player has 3 lives: a wrong number shows red at once and costs one, and the third takes you out (alone, it is game over). Each player has 3 undos, each taking back only the last move; Ctrl or Cmd with Z works too. Easy, medium or hard, a Bot speed option, and a typing and number-pad input. Other players' grids are never sent; the progress lines show only counts. Puzzles are generated by the server, each with one solution.
- Faster first load: each game's script and stylesheet load when its table opens, not on every page. The home page downloads about 519 KB instead of 930 KB, and main-thread blocking at startup is about 40% lower (measured on a throttled phone profile).
- Older iPhones: full-height screens and the table sheets use plain vh values before their dvh values, and the dvh values for custom properties sit behind a feature query, so they still size correctly on iOS before 15.4.
- Wizard on short phones: the trump corner is hidden on 4-player tables (it covered a seat at 320x568); the trump shows in the header there instead.
- Wizard on short phones: the trump suit caption stays visible (on one line) when a Wizard is turned up; it was hidden on 4-player tables under 700px high, so the suit name did not show.
